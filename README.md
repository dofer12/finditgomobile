# FindItGo – איתור פריטים במדף (מחשב + אנדרואיד)

צילום מדפים, זיהוי אוטומטי של קודי פריט (OCR + ברקודים), חיפוש קוד וסימון המיקום המדויק שלו על התמונה.
התמונות נשמרות רק במכשיר (IndexedDB). אפשר לייבא תמונות מ-Google Drive.

## מה יש בתיקייה

| קובץ | תפקיד |
|------|-------|
| `index.html`, `app.js`, `styles.css` | האפליקציה |
| `manifest.json`, `sw.js`, `icons/` | התקנה כאפליקציה ועבודה גם בלי השרת |
| `start.cmd`, `serve.ps1` | הפעלה במחשב (שרת מקומי קטן, בלי התקנות) |

## 1. במחשב (Windows)

1. לחיצה כפולה על `start.cmd` – נפתח `http://localhost:8080`.
2. ב-Chrome או Edge: אייקון ההתקנה בשורת הכתובת (או הכפתור "📲 התקן אפליקציה") ← האפליקציה מקבלת חלון וקיצור דרך משלה.
3. אחרי ההתקנה האפליקציה נפתחת גם כשחלון `start.cmd` סגור. מפעילים אותו שוב רק אחרי שינוי בקבצים.

> לא לפתוח את `index.html` בלחיצה כפולה: כך אין התקנה, אין עבודה בלי רשת ואין חיבור ל-Drive.

## 2. בטלפון אנדרואיד

אנדרואיד מתקין אפליקציית ווב רק מכתובת `https`, ולכן האפליקציה מפורסמת ב-GitHub Pages:
**https://dofer12.github.io/finditgomobile/**

1. בטלפון: פותחים את הכתובת ב-Chrome ← תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית".
2. אותה כתובת עובדת גם במחשב (במקום `start.cmd`).
3. עדכון: כל `git push` לענף `main` מעדכן את האתר תוך דקה-שתיים.

רוצים קובץ APK? אחרי שהאתר באוויר: https://www.pwabuilder.com ← מדביקים את הכתובת ← Package for stores ← Android.

## 3. חיבור Google Drive (פעם אחת, כ-5 דקות)

1. https://console.cloud.google.com ← יוצרים פרויקט חדש (למשל `FindItGo`).
2. APIs & Services ← Library ← `Google Drive API` ← Enable.
3. Google Auth Platform (מסך ה-OAuth consent) ← Get started: שם אפליקציה, מייל, Audience = **External** ← Create.
4. Audience ← Test users ← Add users ← כתובת ה-Gmail שלך.
5. Data access ← Add or remove scopes ← מסמנים `.../auth/drive.readonly` ← Save.
6. Clients ← Create client ← סוג **Web application**:
   - Authorized JavaScript origins: `https://dofer12.github.io` וגם `http://localhost:8080`
   - Authorized redirect URIs: `https://dofer12.github.io/finditgomobile/` וגם `http://localhost:8080/`
   - Create ← מעתיקים את ה-**Client ID**.
7. באפליקציה: "☁️ ייבוא תמונות מ-Google Drive" ← מדביקים את ה-Client ID ← שמור ← התחבר.
   Google יציג "Google hasn't verified this app": זה תקין לאפליקציה פרטית ← Continue.

החלון בתוך האפליקציה מציג בדיוק את שתי הכתובות שצריך להוסיף, עם כפתור העתקה.

טיפ: כדי לא להקליד את ה-Client ID בטלפון, מדביקים אותו פעם אחת ב-`app.js` בשורה `const DRIVE_CLIENT_ID = '';`.

**פרטיות:** הרשאת קריאה בלבד. ההתחברות נשמרת רק עד סגירת האפליקציה (שעה לכל היותר). "התנתק" מבטל גם את ההרשאה אצל Google.

**שימוש:** מדפדפים בתיקיות, מסמנים תמונות (אפשר מכמה תיקיות), ואז "ייבא וסרוק". תמונות שכבר יובאו מסומנות ✓ ולא יובאו פעמיים.

## 4. סנכרון בין המחשב לטלפון

כל מכשיר שומר מאגר משלו. שתי דרכים להעביר:
- "💾 ייצא/ייבא מאגר": `1` לייצוא קובץ במכשיר אחד, `2` לייבוא שלו במכשיר השני.
- שומרים את צילומי המדפים בתיקייה ב-Google Drive ומייבאים אותה בכל מכשיר.

## מגבלות ידועות

- זיהוי הטקסט (OCR) צריך אינטרנט בפעם הראשונה (המנוע נטען מ-CDN, אחר כך נשמר במטמון).
- תמונות HEIC (אייפון) לא נפתחות ב-Chrome: צריך לייבא JPG.
- תווית בודדת על רקע כהה לפעמים לא מזוהה. לחיצה על המקום בתמונה מוסיפה קוד ידנית.
- זיהוי ברקודים אוטומטי עובד ב-Chrome באנדרואיד, לא ב-Windows.
